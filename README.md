# 집값흐름

전국 → 시도 → 구 → 동 → 아파트 순으로 아파트 실거래 흐름을 보는 사이트.
매일 새벽 5시(한국시간) GitHub Actions가 국토부 실거래를 새로 받아 GitHub Pages에 자동 배포함.

## 처음 한 번만 설정 (약 10분)
1. GitHub에서 새 저장소 만들기: 이름 `house-flow`, **Public** 선택
   (무료 계정은 Public 저장소만 Pages 가능. 인증키는 코드에 없고 비밀값으로 따로 보관돼서 안전)
2. 이 폴더의 파일을 전부 업로드 (`.github` 폴더 포함). `.env`는 올리지 않기
3. 저장소 **Settings → Secrets and variables → Actions → New repository secret**
   - Name: `DATA_GO_KR_KEY`, Secret: 공공데이터포털 인증키
4. **Settings → Pages → Build and deployment → Source: GitHub Actions**
5. **Actions 탭 → '매일 자료 갱신' → Run workflow** 로 첫 실행 (약 15~20분)
6. 완료되면 `https://<GitHub아이디>.github.io/house-flow/` 로 접속. 이 주소를 친구에게 공유

## 동작 방식
- `scripts/collect.js`: 144개 시군구, 최근 약 9개월 실거래 수집 → `data/snapshot.json`
- `scripts/build.js`: `site/template.html`에 자료를 압축해 넣어 `dist/index.html` 생성
- 수집이 한 곳이라도 실패하면 배포하지 않고 어제 사이트를 그대로 둠
- 저장소 활동이 60일 없으면 GitHub가 예약 실행을 멈춰서, 매일 `last-updated.txt`를 기록함

## 직접 돌려보기
```
DATA_GO_KR_KEY=인증키 npm run update   # dist/index.html 생성
```

## 화면 규칙
- 전국·시도·시군구 목록: 주별 거래 방향 12주
  - 거래마다 같은 단지·같은 평형의 직전 거래 최근 3건(6개월 안) 중간값과 비교
  - 2% 넘게 비싸면 '올랐어요', 싸면 '내렸어요', 그 사이 '비슷해요'. 해제·직거래 제외
  - 막대 높이 = 비교한 거래 건수, 색 = 올랐어요/비슷해요/내렸어요 비율. '이번 주' = 최근 7일 계약
- 동·아파트: 3개월 평균 추이(15일 간격), 3개월 변동
- 평형·평당가는 공급면적 기준(전용 × 4/3), 공급 1평 이하 차이는 한 평형으로 묶음
- 거래가는 1억 이상이면 20.3억처럼 표시
- 급등·급락(아파트 화면): 평형별 최신 거래가 최근 7일 안이고, 직전 3건 중간값보다 ±10% 이상

## 기타
- `server.js` + `public/`: 예전 실시간 조회 버전 (Render 등 서버 배포용). 자동 갱신 사이트에는 쓰이지 않음
- 지역코드·개편 내역은 아래 참고, 새 개편이 생기면 `site/regions.js`만 수정

## 오류 처리
- 초당 호출 제한·5xx·네트워크 오류: 최대 3회 재시도 (0.4s → 0.8s → 1.6s)
- 인증키 미등록(30)·만료(31)·일일한도(22): 재시도 없이 한글 안내 메시지
- `.env`에 디코딩 키·인코딩 키 어느 쪽을 넣어도 동작
- 가격·면적·날짜가 깨진 행은 제외
